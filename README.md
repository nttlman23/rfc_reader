# Random RFC

Мини-сайт, который открывает **случайную страницу RFC** и даёт кнопку **«Следующий RFC»** (ещё один случайный RFC).

## Как запустить

### Вариант 1 — просто открыть файл

Открой `index.html` в браузере.

### Вариант 2 — локальный сервер (рекомендуется)

Если у тебя есть Node.js:

```bash
npx serve .
```

И открой адрес, который он покажет.

## Файлы

- `index.html` — разметка
- `style.css` — стили
- `app.js` — логика выбора/загрузки RFC
